## Line 1: The Password System — One Account, One Universe

**What it defends against:** Credential stuffing. A password you've leaked on some other site gets tried against Binance automatically.

**How to set it up:**

- Your Binance password **must be different from every other site**, 12+ characters, mixing upper/lowercase, numbers, and symbols
- Generate and store it in a password manager — human-memory passwords almost always follow patterns
- Never reuse the same password between Binance and its registration email — the email is the password-reset back door; if the email falls, the account falls

## Line 2: Two-Factor Authentication — Google Authenticator First, SMS as a Backup

**What it defends against:** Even a leaked password can't open the second door.

**How to set it up:**

- Bind **Google Authenticator**, not SMS-only verification. SIM cards can be hijacked through fraudulent porting (an attacker impersonates you at the carrier and gets a clone of your SIM), so SMS codes are not truly safe
- Binding gives you a set of **backup codes** — write them down offline (paper, a safe). If your phone dies, they're the only lifeline
- Make sure sensitive actions — key resets, withdrawals — are all forced through 2FA

## Line 4: The Withdrawal Whitelist + 24-Hour Protection Period

**What it defends against:** Funds draining out after an account breach. This is the final gate — and the most effective one.

**How to set it up:**

## Line 5: Device and API Management — The Overlooked Side Door

**What it defends against:** Stale logins on old devices, and third-party apps running wild with your API keys.

**How to set it up:**

- Regularly check "Security — Device Management" and **sign out every device** you don't recognize or no longer use; after switching phones, clean out the old device immediately
- If you've created **API keys** for third-party tools (trading bots, charting apps): grant read-only permission, never withdrawal permission, and delete unused keys promptly. Leaked API keys are a leading entry point in recent theft cases
- Never post API keys in group chats, screenshots, or code repositories

## Line 6: Account Structure — Max KYC + Tiered Funds

**What it defends against:** Every risk stacking up on a single account with a single entry point.

**How to set it up:**

- Complete KYC to the highest tier — higher deposit/withdrawal limits, and if your account ever hits an issue, higher-tier verification speeds up appeals and recovery
- Don't pile all your funds into the trading account. Binance supports sub-accounts (available at some tiers) to separate "long-term holdings" from "active trading"; without sub-account access, move idle positions to a hardware wallet for cold storage
- One-line principle: **hot wallet holds what you trade, cold wallet holds what sleeps** — keep only the funds you actually need in the account
