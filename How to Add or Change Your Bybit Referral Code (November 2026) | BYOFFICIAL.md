## 5. Seven Reasons "Adding the Code" Fails

1. **You already deposited or traded.** The golden window has closed. Your only path is customer support.
2. **A referrer was already recorded at sign-up** (someone's affiliate link cookie or a pre-filled code). You can't add a second one.
3. **You clicked another referral link before registering.** Bybit attributes the click, not the code you typed last.
4. **IP or environment flagged.** Sign-ups via VPN / shared IPs sometimes get the referral silently dropped.
5. **Typo or extra space in the code.** Codes are case-sensitive in some entries; check character by character.
6. **Entry no longer exists.** Bybit adjusts the interface over time; the entry may have moved to a different menu.
7. **You waited too long.** Some binding entries expire days after sign-up. The earlier, the better.

**If all fails:** contact support with your UID, registration time, and screenshot of the issue — ask explicitly whether a manual referral attribution is possible. If they say no, the honest answer is: you can register a new account (with a new email/phone) and attach the code correctly this time.
